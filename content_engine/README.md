# AI Content Engine - Mini Building Construction Niche

Autonomous content creation system for TikTok & YouTube Shorts in the **miniature building/construction** niche.

## Modules

1. **Content Idea Generator** — AI-generated viral scripts, hooks, and video concepts
2. **Video Assembler** — FFmpeg-powered vertical video creation with subtitles, music, transitions
3. **YouTube Shorts Uploader** — Auto-upload and schedule via YouTube Data API v3
4. **Caption & Hashtag Optimizer** — Trending captions, hooks, and hashtag generation

## Quick Start

```bash
cd content_engine
pip install -r requirements.txt
python main.py
```
